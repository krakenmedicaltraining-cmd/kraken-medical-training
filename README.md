Kraken Medical Training V7 Foundation

1. Run v7-database-update.sql in Supabase SQL Editor.
2. Upload all V7 files to GitHub, replacing V6.
3. Wait for Cloudflare deployment.
4. Test student-login.html, dashboard.html, games.html and admin.html.

For itch.io games, paste the playable iframe URL containing itch.io/embed-upload/ into a Unity Game block. Normal itch.io project links open in a new tab.

V7 includes learner accounts, cross-device progress, XP, levels, a learner dashboard, and a dynamic simulations library.
