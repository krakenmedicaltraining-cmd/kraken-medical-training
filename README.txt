KRAKEN V15.2 SIMULATION LIBRARY

Replace/add these files in the GitHub repository root:
- admin-v12-5.js
- games.js
- games.html
- simulation-v15.css

No Supabase SQL is required.

Course Builder Simulation blocks now store:
title, simulation_description, URL, simulation_thumbnail_url,
simulation_category, simulation_difficulty, simulation_minutes,
and show_in_sim_library.

Kraken Sim now shows the game as the primary card and the linked
course underneath as "PART OF: Course Name →".

Older simulations remain compatible. Edit an old Simulation block
and fill in the new fields to upgrade its card.
