# Kraken V12.6 Certificates and CPD Records

1. Run `database/v12-6-certificates-cpd.sql` in Supabase SQL Editor.
2. Upload all root-level files from this ZIP.
3. Keep your existing configuration and V12.5 files.
4. Add links where desired:
   - Admin: `certificate-admin.html`
   - Learner record: `cpd-record.html`
5. Redeploy Cloudflare and clear the browser cache.

The update adds certificate configuration, CPD hours, quiz/lesson gating, verification references, printable certificates and a learner CPD record.
