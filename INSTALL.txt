KRAKEN COURSE CONTENT BLOCK FIX

WHAT THIS FIXES

- Image blocks now display inside lessons.
- Video blocks display in their correct block position.
- Reflection blocks are styled and include a learner text area.
- Reflection answers are saved locally on the learner's device.
- Podcast/audio blocks display.
- Download blocks appear inside the lesson and in the Downloads panel.
- Simulation blocks display inside the lesson.
- The course Simulation panel now finds simulations inside lesson blocks.
- Multiple simulations can be shown.
- Existing older courses still work through the fallback fields.

IMPORTANT ABOUT IMAGE LINKS

Use a direct public image URL ending in JPG, PNG, WEBP or a Supabase Storage
public URL. Google Images thumbnail links such as encrypted-tbn0.gstatic.com
may expire or block embedding.

No Supabase SQL is required for this update.

After upload:
1. Redeploy Cloudflare.
2. Fully close and reopen the browser tab.
3. Open the course again.
