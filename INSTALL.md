# Kraken V13 Journal Hub

1. Run `database/v13-journal.sql` in Supabase SQL Editor.
2. Upload:
   - journal.html
   - journal.css
   - journal.js
   - journal-admin.html
   - journal-admin.css
   - journal-admin.js
   - journal-item.html
   - journal-item.css
   - journal-item.js
3. Add `journal.html` to public navigation.
4. Add `journal-admin.html` to admin navigation.
5. Redeploy Cloudflare and clear browser cache.

Content types:
- articles
- videos
- podcasts
- downloads
- news
- events
- case studies
